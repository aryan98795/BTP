# Collected model images

This folder contains copies of all generated model charts, organized by source file, model, and chart type.

- `<source>/comparison/`: model-metric and residual comparisons for one `.iv` source.
- `<source>/models/<model>/`: that model's error-analysis and feature-importance plots.
- `all_files_combined/`: charts from the combined-data comparison.
- `legacy_qe_workflow/`: charts from the earlier QE scripts.

`image_index.csv` maps each image to its source, model, and chart type. These are copies; original charts remain in their existing folders.
